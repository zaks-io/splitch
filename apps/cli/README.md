# @splitch/cli

Command-line interface for operating splitch feature flags and experiments, built for agents and
humans alike.

```sh
npm install --global @splitch/cli
splitch login
```

Run without a global install:

```sh
npx @splitch/cli
```

See the [splitch documentation](https://github.com/zaks-io/splitch/tree/main/docs) for commands and
authentication.
