# Architecture Decision Records

Load-bearing decisions, recorded so future architecture reviews don't re-litigate them. Terse by
design; the format lives in the
[`ziw-grill` planning-artifacts reference](../../.agents/skills/ziw-grill/references/planning-artifacts.md).
Vocabulary follows [CONTEXT.md](../../CONTEXT.md); fuller design narrative lives in
[docs/architecture/](../architecture/).

The ADRs are the index: read the directory. Each file's H1 is its decision. A new ADR takes the next
number after the highest existing prefix. Number 0053 was never used.
